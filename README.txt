BLOSSOMS × INTER-COLLEGIATE FESTIVAL DASHBOARD

1. Install Python on your computer.
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:  py -m pip install -r requirements.txt
5. Run:  py -m streamlit run app.py
6. The dashboard opens in your browser.

The app starts with sample events and sample results. Add events in Event Studio
and enter results in Score Entry. The leaderboard and analytics update automatically.

Note: Data is stored in Streamlit's session state while the app is running.
Download the score register as CSV to keep a copy. This is a student demo app,
not an official live feed from CHRIST University.
